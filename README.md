# AI-Augmented Analytics for Data Visualization: Module 7: Grab Bag

Prompts are on the course page.

## Installation

1. Download and unzip this project, or clone this repository.
2. Install R and Quarto. Open the `.Rproj` file in RStudio, or open the folder in Positron.
3. Run `source("setup.R")` once in the R console.
4. Open `notebooks/07_grab-bag.qmd` and use the prompt from the module guide.
5. Render the completed notebook with `quarto render notebooks/07_grab-bag.qmd` from the project folder.

## Contents

- `notebooks/07_grab-bag.qmd`: the module task.
- `setup.R`: required R packages.
- `_quarto.yml`: notebook rendering settings.
